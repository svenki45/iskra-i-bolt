# Искра и Болт — сборка для телефонов (APK и IPA)

Сборку делает GitHub на своих серверах — ничего ставить на компьютер не нужно. Вы загружаете эту папку в свой репозиторий, GitHub собирает:

- **APK для Android** — ставится на телефон сразу;
- **IPA для iPhone** — без подписи, ставится через Sideloadly или AltStore с вашим Apple ID.

Сборка идёт около 10–15 минут.

## 1. Один раз: репозиторий на GitHub

1. Зайдите на github.com (если аккаунта нет — зарегистрируйтесь, это бесплатно).
2. Справа вверху «+» → **New repository**. Имя, например, `iskra-i-bolt-mobile`. Можно сделать **Private**. Нажмите **Create repository**.
3. На странице нового репозитория нажмите **uploading an existing file** (или **Add file → Upload files**).
4. Перетащите в окно **всё содержимое** этой папки (не саму папку, а то, что внутри: `www`, `assets`, `scripts`, `.github`, `package.json`, `capacitor.config.json`, `.gitignore`, этот файл). Нажмите **Commit changes**.

> Папка `.github` в Windows может быть не видна или браузер может её пропустить. Проверьте, что в репозитории появился файл `.github/workflows/build.yml`. Если его нет: **Add file → Create new file**, в имени наберите `.github/workflows/build.yml`, вставьте содержимое файла `build.yml` из этой папки и нажмите **Commit changes**.

## 2. Сборка

Сборка запускается сама после загрузки. Чтобы запустить её вручную: вкладка **Actions** → слева **Сборка для телефонов** → **Run workflow**.

Когда обе задачи станут зелёными (✓), откройте этот запуск и внизу, в разделе **Artifacts**, скачайте:

- `iskra-i-bolt-android-apk` — внутри `iskra-i-bolt.apk`;
- `iskra-i-bolt-iphone-ipa` — внутри `iskra-i-bolt.ipa`.

(GitHub отдаёт их в zip — распакуйте.)

## 3. Установка на Android

1. Перекиньте `iskra-i-bolt.apk` на телефон (кабель, Telegram «Избранное», Google Drive).
2. Откройте файл на телефоне. Android попросит разрешить установку из этого источника — разрешите.
3. Игра появится на рабочем столе. Она открывается на весь экран, в альбомной ориентации, экран не гаснет.

## 4. Установка на iPhone

Apple не разрешает ставить приложения не из App Store без подписи. Бесплатный способ:

1. На компьютере установите **Sideloadly** (sideloadly.io) и iTunes.
2. Подключите iPhone кабелем, откройте Sideloadly, перетащите `iskra-i-bolt.ipa`, введите свой Apple ID и нажмите **Start**.
3. На iPhone: **Настройки → Основные → VPN и управление устройством** → доверьте свой Apple ID. На iOS 16+ ещё включите **Настройки → Конфиденциальность → Режим разработчика**.

С бесплатным Apple ID приложение работает 7 дней, потом его нужно переустановить через Sideloadly. С платным аккаунтом разработчика Apple ($99 в год) — год, и можно выложить в TestFlight.

## Управление на телефоне

- Сенсорные кнопки появляются сами. Их можно двигать и менять размер, как в мобильной GTA:
  - в кампании — Пауза → «Настроить сенсор» (или Настройки → «Кнопки и размер экрана»);
  - в арене — меню арены → «Сенсорные кнопки» (у арены своя раскладка).
- Подключённый геймпад тоже работает.
- Конструктор уровней на телефоне скрыт — он рассчитан на мышь.

## Как обновить игру

Когда выходит новая версия, замените файл `www/index.html` в репозитории (Add file → Upload files, перетащить новый `index.html` в папку `www`). Сборка запустится сама.

Если что-то не собирается — откройте красный (✗) запуск в Actions, нажмите на упавший шаг и пришлите текст ошибки.
