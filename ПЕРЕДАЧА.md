## 2. Что за игра
Кооперативный 2D-платформер на двоих (одна клавиатура / геймпады / онлайн по коду комнаты) или соло. Герои: **Искра** (огонёк, стреляет огнём, двойной прыжок, рывок, пролезает в щели) и **Болт** (робот, толкает ящики, удар сверху, тяжёлые гайки). 100 уровней, 10 глав, каждый 10-й — босс. Боссы: **Пресс-Жаба (toad), Око-Сварщик (eye), Бешеная Шестерня (gear), Королева Жуков (queen), Главный Механизм (core)**, у каждого версии I–III.

Технически: **один HTML-файл**, canvas 1280×720 (клетка 40 px), 3D-окружение на Three.js r149 под 2D-холстом. Герои/враги/боссы — всегда 2D-спрайты (автор так хочет), окружение — 3D.

## 3. Что уже сделано (версия v1.16)
- **3D всегда включено** (переключателя нет; если WebGL нет — запасной 2D).
- **Конструктор уровней**: тайлы, декор (26 предметов, поворот Q/E, размер Shift+колесо, R отражение, F передний план), лампы и «Дверь света», тьма, уровни с боссом, случайный уровень, сохранение/импорт.
- **«Моя игра»**: кампания из своих уровней, сохранение в файл.
- **Бой**: шипы отнимают сердце (не убивают сразу), пули разбиваются о ящики/платформы, стрелка на босса за экраном, **карта уровня по удержанию Tab / Select** (кнопка переназначается в «Кнопках»).
- **Смерть**: герой рассыпается на атомы, затемнение, замедление, наезд камеры; окно «Вы повержены» поверх застывшей сцены.
- **Титульный экран**: сварка логотипа + удар, металлическая плашка «3D», силуэты 5 боссов на горизонте с глазами, живой цех (лампы, пар, сварка), своя музыка, сценки боссов при бездействии, 3D-лента-платформа, герои бегут и перепрыгивают пули.
- **Интерфейс**: крупное окно игры, без описаний уровня сверху, без подсказок внизу меню, единое выделение кнопок (мышь = клавиатура), «На главный экран» в меню, кнопки Конструктор/Моя игра на стартовом экране.
- **Ролики (3D-мир + 2D-персонажи)**: **пролог** и **ролик после победы над Жабой** (стрельба → «Ква-а… это ещё не конец!» → прыжок в окно «Я вернусь… и стану сильнее!» → герои подбегают и дают пять → уходят дальше).
- **Эмоции Жабы в бою**: злая, при попадании морщится от боли.
- Онлайн: понятный экран «Создаём комнату…».
- Прочее ранее: сложности и НИ+, звёзды/рекорды, комбо, поднятие напарника, лёд/порталы/ломкие мосты/ветер, языки ru/uk/en, заставка и демо.

### Как устроен код
- Файлы `src-pc/*.js` склеиваются **по алфавиту** в один скрипт, общая область видимости. То, что нужно при загрузке, должно быть в файле с меньшим номером (`27a_decor` раньше `27b_editor`).
- Ключевое: `05_levels` (генератор, `getLevel`), `07_state` (`loadLevel`), `09_players` (`hurt`), `11_boss`, `14_world` (`complete`, `die`, атомы), `15_overlays_menus` (`setState` — все экраны), `17_loop`, `20_backdrops_live_and_draw` (`draw`, `drawBoss`, `drawSpark/drawBolt`, мини-карта, стрелка), `21_cinematics` (пролог, ролик Жабы `drawToadOutro`, титульный экран), `27_render3d` (3D уровней), `27b_editor` (конструктор), `27c_cine3d` (3D-сцены роликов: `CINE3D.prologue(t)`, `CINE3D.toad(t)`), `02_layout` (вставка CSS для ПК).
- Ролики идут через состояние `prologue`, режим выбирает `proMode` (`'pro'` / `'toad'`). Ролик Жабы запускается из `complete()` перед обычным экраном после босса.
- Эмоции босса: поле `b.emo` (`'angry'`/`'pain'`) в `drawBoss`; в бою для Жабы ставится автоматически.
- Тест-хуки в странице: `window.__ib` (`setState`, `getLevel`, `complete`, `hitBoss`, `demoAt`, `proAt`, `cine('toad')`, `state`…).

### Выпуск новой Steam-сборки
1. Правки в `source/src-pc/`.
2. `cd source && python build_all.py`, открыть `out/steam.html` в Chrome, F12 → без красных ошибок.
3. Скопировать `out/steam.html` → `desktop-app/index.html`, закоммитить, запушить.
4. GitHub Actions соберёт `iskra-i-bolt-desktop.zip` (Releases → `desktop`, ~110 МБ). Распаковать, запустить `Iskra i Bolt.exe` (F11/Alt+Enter — оконный режим).

## 6. Важные мелочи
- Windows SmartScreen ругается на неподписанный exe — для теста «Подробнее → Выполнить в любом случае»; в Steam этого не будет.
- Онлайн работает через публичные MQTT-брокеры + WebRTC; версии онлайна должны совпадать (`NET_VER=3`).
- Сохранения и свои уровни хранятся в localStorage приложения; переносить через «Моя игра → Сохранить игру в файл».
- Внизу слева в игре: «v1.16 · сборка ДД.ММ ЧЧ:ММ» — по этому видно, свежая ли сборка.
