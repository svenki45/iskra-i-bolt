# «Искра и Болт» — введение для ИИ-помощника (Gemini, Claude и др.)

Прочитай этот файл целиком перед любой правкой. Автор игры — Edward Dergachev, он не программист, а «вайб-кодит»: объясняй по-русски, просто и коротко, без лишних терминов.

## Главное правило автора
**«Главное, чтобы не сломалось то, что уже работает».** Каждое изменение: маленькое, проверенное в браузере, без переписывания рабочих частей. Если не уверен — сначала спроси.

## Что за игра
Кооперативный 2D-платформер на двоих (одна клавиатура / геймпады / онлайн) или соло: **Искра** (огонёк, стреляет огнём) и **Болт** (робот, подбрасывает и бьёт). 100 уровней, 10 глав, каждый 10-й уровень — босс (5 боссов: toad, eye, gear, queen, core, у каждого версии I–III). Есть Лавка, достижения, звёзды, сложности, НИ+, тьма, лёд, порталы, ветер, ломкие мосты, ролики, демо-режим, языки ru/uk/en, онлайн, 3D-фон (Three.js) за 2D-холстом.

Всё — **один HTML-файл** с canvas, без сервера и без npm. Логический экран 1280×720, клетка T=40, 32 колонки × 18 рядов на экран.

## Как собрать
```
cd source
python build_all.py
```
Получится `source/out/pc.html`, `out/mobile.html`, `out/long.html`. Открыть в Chrome, проверить. Если всё ок — скопировать `out/long.html` → `long/index.html` (или `out/pc.html` → `pc.html`) и запушить; GitHub Pages обновится за минуту.
(В живых `pc.html`/`index.html` наверху ещё PWA-строки — manifest, иконки. При замене их надо сохранить.)

## Как устроен код (важно!)
- Файлы `src/*.js` склеиваются **по алфавиту** в один скрипт и живут в **одной общей области видимости**. Порядок имеет значение: то, что используется при загрузке, должно быть объявлено в файле с меньшим номером (поэтому `27a_decor.js` идёт раньше `27b_editor.js`).
- Карта уровня — массив строк, каждый символ — клетка: `#` стена, `.` пусто, `^` шипы, `1`/`2` старт Искры/Болта, `E` выход 2×2, `C` ящик, кнопки/двери/мосты по цветам `P Q R`, `D` дверь света, `a b c` + `G` кнопки по порядку, `h` рычаг, `k` ключ, `X` замок и т.д. (полный список — `TOOLS` в `27b_editor.js`).
- Ключевые места: `getLevel(i)` (05_levels), `loadLevel(i)` (07_state), `complete()` (14_world), `setState(...)` — все меню (15_overlays_menus), главный цикл (17_loop), рисование (18–20).
- Длинные уровни: `longLevel(i)` склеивает 3 экрана; `COLS`/`WW` — переменные ширины, камера следует за героями.
- Конструктор (`27b_editor.js`, IIFE `ED`): палитра с поиском и подсказками, тест-запуск (`edTest/edLevel`), сохранение в localStorage `iskra-bolt-mylevels`, черновик `-draft`, «Моя игра» — `-game`. Уровень → игровой объект через `toGame()`.
- Декор (`27a_decor.js`): объект `DECOR`, у предмета `{t,tx,ty,sc,fl,fr,rot}` — тип, клетка, масштаб, отражение, передний план, поворот в градусах.
- Лампы: `L.lampsC` → `lamps`, режимы touch/timer/plate:P|Q|R/lever, радиус `r`, густота тьмы `darkA`.
- Для автотестов в странице есть `window.__ib` (getLevel, complete, setState, hitBoss, state…).

## Как проверять
Открыть собранный HTML в Chrome, F12 → Console: **не должно быть красных ошибок**. Пройти то, что менял: меню, уровень, конструктор (тест-запуск), смерть, переход на следующий уровень, 2 игрока и соло.
