# Искра и Болт — исходный код по частям

Сборка: `python3 build.py` склеивает файлы `src/*.js` по порядку имён в `game.js`
и собирает из него `iskra-i-bolt.html` (ПК) и `iskra-i-bolt-mobile.html` (телефон).
`python3 build.py --pc-only` — только ПК-версия.

Все части лежат в одной общей области видимости (как один файл), поэтому порядок важен.

| Файл | Что внутри |
|---|---|
| 00_header | начало, уровни-обучение (TUTORIAL) |
| 01_i18n | переводы ru/uk/en на лету |
| 02_layout | размер экрана, полноэкранный режим |
| 03_audio | музыка, звуки, голоса |
| 04_input | клавиатура, геймпады, управление героями, ИИ напарника |
| 05_levels | генератор уровней, механики, сложность |
| 06_profile | достижения, внешний вид, настройки, прокачка |
| 07_state | состояние игры, тьма, загрузка уровня, секреты |
| 08_collision | столкновения и движение |
| 09_players | управление героями, стрельба, урон |
| 10_enemies | враги |
| 11_boss | боссы |
| 12_boss_outro | ролик гибели босса |
| 13_bullets_pickups | пули, бонусы, рюкзак |
| 14_world | мир: двери, кнопки, выход, падения, звёзды |
| 15_overlays_menus | все меню и экраны (setState) |
| 16_save_slots | слоты сохранений, новая игра, НИ+ |
| 17_loop | главный цикл, платформы, новые механики |
| 18_drawing | базовое рисование |
| 19_backdrops_names | фоны по названиям уровней |
| 20_backdrops_live_and_draw | живые фоны, герои, враги, HUD, draw() |
| 21_cinematics | пролог, финал, титульная сцена |
| 22_boot | запуск |
| 23_touch | сенсорное управление |
| 24_online | онлайн-игра (MQTT + WebRTC) |
| 25_demo_splash | демо-режим, заставка |
| 26_touch_polish | подгонка меню под экран, вкладки |
| 27_render3d | 3D-окружение (Three.js) |
| 28_final_init | финальная инициализация, версия |
